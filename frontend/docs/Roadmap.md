# Roadmap — WB Аналитика

## Версия 0.1 — MVP (✅ Завершено)

**Цель:** Рабочий прототип с авторизацией и базовой валидацией токена.

- [x] Регистрация / вход (телефон + email)
- [x] Профиль с 3-шаговым мастером
- [x] Базовая валидация токена (Content API)
- [x] Личный кабинет
- [x] Тикеты поддержки
- [x] WB-консультант (Yandex GPT)
- [x] Административная панель

---

## Версия 0.2 — Полная валидация токена (✅ Завершено)

**Цель:** Соответствие требованиям ТЗ по валидации токена.

- [x] Проверка ping всех 5 категорий WB API (Контент, Аналитика, Маркетплейс, Статистика, Финансы)
- [x] Пошаговый индикатор в UI с отображением статуса каждого шага
- [x] Корректное сообщение при отсутствии доступа к категориям
- [x] Автовыгрузка данных продавца после валидации (`/seller-info`)
- [x] Сохранение рейтинга продавца (`/rating`)
- [x] Хранение даты истечения токена (180 дней), предупреждение за 14 дней
- [x] Автозаполнение полей компании / ИНН из WB API
- [x] Кнопка «Обновить токен» на странице профиля
- [x] Обновление README, Backlog, Roadmap

---

## Версия 0.3 — Безопасность и уведомления (📋 Запланировано)

**Цель:** Production-готовность по безопасности.

- [ ] Шифрование токенов в БД (AES-256 или интеграция с Vault)
- [ ] Email-уведомления за 14 дней до истечения токена
- [ ] 2FA (TOTP) для входа в аккаунт
- [ ] Защита от брутфорса (rate limit на `/api/auth/*`)
- [ ] Аудит лог истории изменений токена (таблица `token_update_log`)

---

## Версия 0.4 — Навигация аналитики и каркас синхронизации (📋 Запланировано)

**Цель:** Подготовить интерфейс и серверный каркас для последовательной загрузки данных WB.

- [ ] Hamburger-меню в Личном кабинете с разделами новых шаблонов: Главная сводка, Товары, Остатки, Финансовые отчёты, Расходы, Настройки синхронизации
- [ ] Серверный модуль WB auth для единообразной передачи токена в API WB
- [ ] Клиенты WB API: balance, content, fby, fbs, prices, finance
- [ ] Универсальные helper-модули: cursor pagination, rrdId pagination, polling асинхронных задач
- [ ] Журнал запусков синхронизации и выключенное по умолчанию трассирование WB-запросов
- [ ] Документированный протокол тестирования методов WB для текущего дня и текущей недели

---

## Версия 0.5 — Оперативная сводка и товарный кэш (📋 Запланировано)

**Цель:** Получать данные, которые нужны Dashboard и товарным разделам без ожидания закрытия финансовых отчётов.

- [ ] Баланс продавца (`GET /api/v1/account/balance`) с обновлением при открытии Dashboard и по кнопке "Обновить"
- [ ] Кэш справочников Content API: родительские категории, предметы, характеристики, цвета, бренды
- [ ] Кэш карточек через `POST /content/v2/get/cards/list`: фото, артикулы, бренд, категория, цвет, размеры, skus
- [ ] Остатки FBY через `warehouse_remains`: создать отчёт, дождаться `done`, скачать JSON
- [ ] Остатки FBS по складам продавца и всем chrtID из карточек
- [ ] Товары: таблица с фото, артикулом, брендом, категорией, цветом, ценой, остатком
- [ ] Остатки: разрез FBY / FBS, склад, размер, barcode
- [ ] Оперативные показатели заказов, продаж / выкупов, отказов и возвратов после проверки методов WB

---

## Версия 0.6 — Финансовые отчёты и прибыль (📋 Запланировано)

**Цель:** Сопоставлять закрытые финансовые отчёты с товарным кэшем и считать чистую прибыль.

- [ ] Отчёты реализации: список отчётов, детализация по reportId, детализация за период с rrdId-пагинацией
- [ ] Отчёты эквайринга: список отчётов, детализация по reportId, детализация за период с rrdId-пагинацией
- [ ] Обогащение финансовых строк данными карточек по nmID и srid перед отображением
- [ ] Финансовые фильтры: тип операции, бренд, период
- [ ] Себестоимость товаров (ввод вручную + импорт из Excel)
- [ ] Управление рекламными расходами и дополнительными расходами
- [ ] Расчёт чистой прибыли: выручка минус расходы WB, эквайринг, реклама, закупка, фулфилмент, налоги и прочие расходы

---

## Версия 1.0 — Полноценная платформа (📋 Долгосрочно)

**Цель:** Готовый B2B SaaS для аналитики Wildberries.

- [ ] Мультикабинет (несколько marketplace_connections на пользователя)
- [ ] Интеграция с таблицами Supabase (migrate от SQLite)
- [ ] Сравнительная аналитика периодов
- [ ] Экспорт отчётов в Excel / PDF
- [ ] API для партнёров
- [ ] Мобильная версия (PWA)
- [ ] Webhook-уведомления (новые заказы, изменения статусов)
