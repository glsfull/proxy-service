# Руководство пользователя

Документ описывает работу с дашбордом аналитики и генератором этикеток. Приложение построено на Nuxt 3 + Nuxt UI и работает в браузере.

## Запуск

1. Установите Node.js 20+ (рекомендуется 22+) и npm 9+.
2. В директории `frontend/` выполните `npm install`.
3. Запустите `npm run dev` и откройте `http://localhost:3000`.

## Главная страница

- Слева расположено боковое меню с пунктом **«Генератор этикеток маркетплейсов»**.
- Шапка содержит заголовок страницы и три действия: **Предпросмотр**, **Скачать PDF** и **Сохранить**.
- Под шапкой расположены вкладки маркетплейсов: Wildberries (готов), Ozon и Яндекс Маркет (отмечены «скоро»).

## Сценарий «Wildberries»

### Карточки товаров

1. На вкладке **Wildberries** отображается список карточек, выгруженных по API.
2. Карточки автоматически отсортированы по артикулу.
3. На каждой карточке видны фото, название, артикул, вендоркод, бренд и количество размеров.
4. Нажмите карточку, чтобы перейти к подготовке этикеток.

### Настройки этикетки

В верхней панели можно настроить:

- **Штрихкод** — выбор номера штрихкода (1‑й, 2‑й или 3‑й) для печати.
- **Размер** — отображение размера: производителя, российского или комбинированного («Пр/Рос»).
- **Тип** — носитель: А4 или термоэтикетка.
- **Этикетка** — формат термоэтикетки (например, 58×40 или 75×120 мм). Доступен только при выборе типа «Термо».
- **Формат** — кодировка штрихкода: CODE128, EAN13 или CODE39.
- **Шрифт** — размер текста этикетки в пикселях (от 6 до 16).
- **Текст** — выравнивание текста (по центру или слева).
- **Доп. поля** — раскрывающийся блок с переключателями: «Срок годности», «Страна», «Бренд», «Состав», «Поставщик», «Свободная надпись», «EAC».

### Предпросмотр

- Под панелью настроек отображается макет одной этикетки. Размер шрифта и выравнивание применяются мгновенно.
- Справа от макета доступен пейджер — кнопка с номером выбирает строку для предпросмотра.
- Подпись под пейджером показывает соответствие выбранного штрихкода формату.
- Нажатие **Предпросмотр** в шапке формирует HTML-снимок всех этикеток. Снимок виден прямо на странице и может быть скопирован.
- Кнопка **Скачать PDF** открывает HTML-снимок в новом окне браузера и автоматически вызывает диалог печати — выберите «Сохранить как PDF», чтобы получить файл.

### Таблица размеров

- Каждая строка соответствует одному размеру/штрихкоду.
- Поля редактируются по клику. Размер слева отображается в формате, выбранном настройкой.
- В шапке любых редактируемых колонок доступно поле «Для всех…»: введите значение и нажмите ✓ или Enter, чтобы применить ко всем строкам.
- Включение дополнительных полей добавляет соответствующие колонки в таблицу.
- В колонке «Кол-во» допустимы только целые значения ≥ 1. Массовый ввод тоже округляется к 1, если введено меньшее значение.

### Сохранение и возврат

- Нажмите **Сохранить** — кнопка покажет «✓ Сохранено» и через две секунды вернёт исходный заголовок.
- Кнопка **Все товары** возвращает к списку карточек.

## Запуск тестов и проверки типов

В директории `frontend/`:

```bash
npm test
npm run typecheck
```

## Регенерация бэклога

В директории `frontend/`:

```bash
npm run baklog
```

Скрипт перезаписывает корневой файл `baklog.md` актуальным состоянием текущих и запланированных работ.
