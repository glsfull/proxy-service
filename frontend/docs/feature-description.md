# Описание функционала

## Общая структура интерфейса

- Каркас приложения — Nuxt 3 + Nuxt UI. Точка входа: `frontend/app/app.vue` рендерит `<NuxtPage />`.
- Главная страница `frontend/pages/index.vue` собирает дашборд аналитики с боковым меню и рабочей областью.
- Источник данных и типы лежат в `frontend/utils/marketplaceLabels.ts`. Логика этикеток — в `frontend/utils/labelSettings.ts`. Работа с редактируемой таблицей — в `frontend/utils/productRows.ts`. Генератор бэклога — в `frontend/utils/baklog.ts`.

## Карточки товаров (Wildberries)

- Список карточек сортируется по артикулу через `sortProductsByArticle()`.
- Каждая карточка отображает фото, название, артикул, вендоркод, бренд и количество размеров.
- При выборе карточки страница переключается в детальный режим.

## Детальный режим: настройки этикетки

Состояние настроек создаётся через `defaultLabelSettings()` и сохраняется в `reactive`-объекте Vue:

- `barcodeIndex` — выбор активного штрихкода (1‑й, 2‑й или 3‑й).
- `sizeDisplayMode` — режим отображения размера: `tech`, `wb` или `both`.
- `mediaType` — носитель: `a4` или `thermal`.
- `thermalSize` — формат термоэтикетки из массива `THERMAL_SIZES`.
- `barcodeFormat` — `CODE128`, `EAN13` или `CODE39`. Корректность каждого штрихкода проверяется функцией `isValidBarcode()`.
- `fontSize` — размер шрифта в пикселях, ограничивается `clampFontSize()` диапазоном 6–16.
- `textAlign` — выравнивание текста: по центру или слева.
- `additionalFields` — набор переключателей дополнительных колонок и блоков предпросмотра (срок годности, страна, бренд, состав, поставщик, свободная надпись, EAC).

## Детальный режим: предпросмотр

- Предпросмотр одной этикетки с переключаемой строкой через пейджер.
- Подпись под пейджером сообщает, соответствует ли штрихкод выбранному формату (используется `isValidBarcode()`).
- Кнопка **Предпросмотр** в шапке формирует общий HTML-снимок всех этикеток (`buildPreviewHtml()`), включая дополнительные блоки и EAC. HTML экранируется через `escapeHtml()` для безопасности.
- Кнопка **Скачать PDF** открывает снимок в новой вкладке и вызывает `window.print()`. Пользователь сохраняет PDF из стандартного диалога печати.

## Детальный режим: таблица

- Таблица строится по результатам `buildProductRows()` и хранится в реактивном `ref`.
- Поддерживаются bulk-инпуты в шапке: `applyBulkValue()` обновляет указанное поле сразу во всех строках. Значения количества округляются до целого ≥ 1.
- Любое одиночное редактирование вызывает `updateRow()` и не мутирует исходный массив, что облегчает интеграцию с историей изменений.
- Колонки появляются и исчезают синхронно с переключателями дополнительных полей.

## Сохранение состояния

- `Сохранить` запускает `handleSave()`, отображает «✓ Сохранено» на 2 секунды. Подключение к Supabase запланировано в бэклоге.
