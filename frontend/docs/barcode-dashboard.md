# Документация: генератор этикеток маркетплейсов

## Руководство пользователя

1. Откройте фронтенд-приложение и выберите пункт меню "Генератор этикеток маркетплейсов".
2. На странице доступны вкладки "Wildberries", "Ozon" и "Яндекс Маркет".
3. Перейдите во вкладку "Wildberries". После выгрузки данных по API пользователь видит карточки товаров, отсортированные по артикулу.
4. В карточке товара отображаются фото, название, артикул, вендоркод, бренд и количество размеров.
5. Нажмите на карточку товара, чтобы открыть экран подготовки этикеток по размерам.
6. На детальном экране доступны настройки этикетки, предпросмотр, кнопки "Предпросмотр", "Скачать PDF" и "Сохранить".
7. В таблице отображаются строки по каждому размеру и штрихкоду с колонками: "Штрихкод", "Артикул", "Цвет", "Размер", "Название товара", "Наименование продавца", "Бренд" и "Кол-во".
8. Кнопка "Все товары" возвращает пользователя к списку карточек Wildberries.

## Описание функционала

- Страница в меню называется "Генератор этикеток маркетплейсов".
- Верхний уровень интерфейса построен на вкладках маркетплейсов: Wildberries, Ozon и Яндекс Маркет.
- В текущей версии проработан сценарий Wildberries, а вкладки Ozon и Яндекс Маркет подготовлены для следующего этапа.
- Wildberries-товары выводятся карточками после API-выгрузки и сортируются по артикулу.
- Каждая карточка показывает фото, название, артикул, вендоркод, бренд и количество размеров.
- Клик по карточке открывает детальную таблицу штрихкодов и размеров.
- Таблица использует структуру, необходимую для печати этикеток: штрихкод, артикул, цвет, размер, название товара, продавец, бренд и количество этикеток.
- Предпросмотр этикетки показывает выбранный штрихкод, артикул, цвет, размер, бренд и знак EAC.

## Алгоритм работы

1. Система получает товары Wildberries через API.
2. Товары нормализуются в структуру карточек: фото, название, артикул, вендоркод, бренд, размеры.
3. Список карточек сортируется по артикулу.
4. Пользователь выбирает товар.
5. Система открывает детальный экран и строит строки таблицы по размерам выбранного товара.
6. Пользователь проверяет предпросмотр и таблицу, затем сохраняет результат или скачивает PDF.

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Для проверки логики:

```bash
npm test
```
