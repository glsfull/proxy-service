## Сценарий пользователя

1. Откройте фронтенд-приложение и выберите пункт меню **«Генератор этикеток маркетплейсов»**.
2. На странице доступны вкладки **Wildberries**, **Ozon** и **Яндекс Маркет**.
3. Перейдите во вкладку **Wildberries**. После выгрузки данных по API пользователь видит карточки товаров, отсортированные по артикулу.
4. В карточке товара отображаются фото, название, артикул, вендоркод, бренд и количество размеров.
5. Нажмите карточку, чтобы открыть экран подготовки этикеток.
6. На детальном экране доступны переключатели позиции штрихкода, режима размера, типа носителя (А4/Термо), формата термоэтикетки, формата штрихкода (CODE128/EAN13/CODE39), размера шрифта и выравнивания текста.
7. Дополнительные поля включаются переключателями: «Срок годности», «Страна», «Бренд», «Состав», «Поставщик», «Свободная надпись», «EAC». Колонки таблицы и предпросмотр обновляются мгновенно.
8. Над таблицей виден предпросмотр этикетки с пейджером строк и подсказкой о соответствии штрихкода выбранному формату.
9. В шапке таблицы доступны поля «Для всех…» — массовое заполнение колонок одним значением.
10. Кнопки **Предпросмотр**, **Скачать PDF** и **Сохранить** доступны в шапке. PDF создаётся из HTML-снимка через системный диалог печати.

## Алгоритм работы

1. Список товаров получается через API (в текущей версии — мок `wildberriesProducts`).
2. Карточки нормализуются и сортируются по артикулу (`sortProductsByArticle`).
3. При выборе карточки строки таблицы строятся через `buildProductRows()` и поддерживают bulk-обновления.
4. Настройки этикетки управляются объектом `LabelSettings` с дефолтами из `defaultLabelSettings()`.
5. Корректность штрихкодов проверяется `isValidBarcode()` под выбранный формат.
6. Предпросмотр и PDF строятся из HTML-снимка с экранированием значений.
7. Бэклог генерируется командой `npm run baklog` (скрипт `frontend/scripts/generate-baklog.ts`) и сохраняется в корневом `baklog.md`.
